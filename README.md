# Atlas English

Atlas English is a responsive web game for Vietnamese learners building English foundations for IELTS Academic.

## Current implementation gate

Only `VS-01` is open. The current application is a technical foundation, not a playable game. Supabase, Vercel, authentication, persistence and gameplay are intentionally absent.

## Local requirements

- Node.js 24.19.x
- npm 11.17.x

## Commands

```text
npm install
npm run dev
npm run check
```

The full product scope, approval boundary and sequential gates are defined in `PLAN.md` and `docs/VERTICAL-SLICE.md`.
